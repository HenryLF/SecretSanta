Unstrict Mode:

(Will not try to enforce all constraint)

This program helps doing draft for Secret Santa.
Each family is mutualy exclusive (members of the same family cannot offer gift to each other).

The "0" Button define other mutualy exclusive group.
e.g. : Natasha and Sasha hate themselves, if they are both group 1 they won't have to offer gift to each other.
The group 0 brings no constraint.
